One line roasting a smart fridge that locks itself after midnight — and then lectures its owner about their choices.

## Run

```sh
python3 main.py
```

Writes the roast to `/output/entry.txt`. Set `OUTPUT_PATH` to write somewhere else:

```sh
OUTPUT_PATH=entry.txt python3 main.py
```
